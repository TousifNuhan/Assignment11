## Category
Online Group Study

## Features

- User authentication with Firebase and JWT
- Create assignments with difficulty levels and due dates
- Submit assignments with PDF/Doc links and notes
- Grade pending assignments submitted by other users
- Theme toggle (Light/Dark mode)
- Assignment filtering by difficulty level
- Responsive design for mobile, tablet, and desktop

## Technologies Used

- React
- Firebase Authentication
- Node.js
- Express.js
- MongoDB
- JWT
- TanStack Query
- Tailwind CSS
